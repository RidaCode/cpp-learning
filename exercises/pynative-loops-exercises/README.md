# C++ Loop Exercises

My solutions to the [PYnative C++ Loops Exercises](https://pynative.com/cpp-loops-exercises/), a collection of 31 practice problems covering loops and control flow in C++.

I'm working through these exercises to get more comfortable with `for` loops, `while` loops, nested loops, and general problem-solving. The code here represents my own attempts, not PYnative's provided solutions.

## Topics

- Loop fundamentals - sequences, sums, factorials, and multiplication tables
- Number problems - digits, primes, Fibonacci, GCD, and LCM
- Strings and arrays - counting characters, sums, and min/max values
- Nested loops - star patterns, number patterns, and multiplication charts
- Other control-flow challenges
